## 🚀 About Me

- 🔬 **AI & RAG Specialization:** Architecting grounded Retrieval-Augmented Generation (RAG) engines with multi-tier fallback hierarchies (Local Ollama → Groq LPU → Heuristic failsafes), vector databases (`ChromaDB`), and document citation pipelines.
- 🌊 **Scientific Data & Geospatial 3D:** Transforming massive spatial datasets (NetCDF, xarray, 10,800+ ARGO oceanic profiles) into interactive 3D WebGL globes and live telemetry dashboards.
- 🗣️ **Conversational & Vernacular AI:** Crafting voice-first agents and regional dialect mentors (Mewari, Hindi, Gujarati) powered by Web Speech APIs and custom prompt architectures.
- 🎓 **Academic Background:** Mohan Lal Sukhadia University (MLSU), Udaipur, Rajasthan.
